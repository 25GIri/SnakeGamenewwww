# SnakeGamenewwww

A classic Snake game built with HTML5 Canvas and JavaScript.

## Features
- Smooth grid-based movement
- Score tracking
- Retro arcade styling
- Responsive arrow key and WASD controls

## How to Play
1. Open `index.html` in any modern web browser.
2. Use **Arrow Keys** or **WASD** to steer the snake.
3. Eat the red food to grow and increase your score.
4. Avoid hitting the walls or your own tail! Press **Space** to restart when game over.
